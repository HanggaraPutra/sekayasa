# Seka Yasa — Website Portofolio & Profil Perusahaan

Website portofolio multi-halaman untuk **Seka Yasa (Surabaya)** — Software House, Pengembangan Aplikasi Web, dan Konsultan Sistem Informasi Perusahaan (POS Multi-Cabang, ERP Gudang & Produksi, serta Sistem Informasi Manajemen Internal).

## Struktur Halaman
- `index.html` — Beranda (5 bagian penuh: Split-Plane Hero, Ledger Masalah Lapangan, Workbench Sistem Interaktif, Rel Cara Kerja, & Lokasi Surabaya)
- `projects.html` — Detail 3 Studi Kasus Utama (ERP, POS Multi-Cabang, Manajemen Internal & HRIS)
- `about.html` — Profil Perusahaan, Filosofi *Saka Guru & Yasa*, serta Prinsip *Tata • Titi • Tentrem*
- `contact.html` — Asesmen 3-Klik ke WhatsApp & Peta Lokasi Surabaya
- `DESIGN_SYSTEM.md` — Dokumentasi Lengkap Karakteristik Desain (*Warm Javanese Modern Studio*)

## Konfigurasi
Untuk mengganti nomor WhatsApp tujuan konsultasi, edit `SEKA_CONFIG.whatsappNumber` di dalam file `app.js`.
